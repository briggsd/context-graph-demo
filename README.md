# my-app — Software Engineering Context Graph

[![Neo4j Labs](https://img.shields.io/badge/Neo4j_Labs-blue?logo=neo4j)](https://neo4j.com/labs/)

Software development lifecycle, repositories, issues, deployments, and team collaboration

> AI-powered Software Intelligence

Built with [create-context-graph](https://github.com/neo4j-labs/create-context-graph) · Agent Framework: **PydanticAI**

> **Neo4j Labs Project** — Generated by create-context-graph, a [Neo4j Labs](https://neo4j.com/labs/) project. Maintained by Neo4j staff and the community, but not officially supported.

## Quick Start

```bash
# Install dependencies
make install

# Start Neo4j (Docker)
make docker-up

# Seed sample data
make seed

# Start the application
make start
```

- **Backend:** http://localhost:8000
- **Frontend:** http://localhost:3000
- **Neo4j Browser:** http://localhost:7474

## Domain: Software Engineering

These entity types are shared across all domains using the Person-Organization-Location-Event-Object model:

- **Person** — PERSON
- **Organization** — ORGANIZATION
- **Location** — LOCATION
- **Event** — EVENT

- **Issue** — EVENT

## Agent Tools

The AI agent has access to the following domain-specific tools:

- **search_developer** — Search for developers by name or role
- **get_service_health** — Get the health status and dependencies of a service
- **find_similar_incidents** — Find past incidents similar to a current one
- **get_deployment_history** — Get deployment history for a service
- **get_pr_impact** — Trace the impact of a pull request through deployments and incidents
- **list_repositories** — List Repository records with optional limit
- **get_repository_by_name** — Get a specific Repository by name with all connections
- **execute_cypher** — Run ad-hoc Cypher queries
- **get_schema** — View the graph schema

## Agent Framework: PydanticAI

This project uses [PydanticAI](https://ai.pydantic.dev/) with tool decorators and typed dependencies. The agent is defined in `backend/app/agent.py` using `@agent.tool` decorators for each domain tool. Supports full streaming via `agent.run_stream()`.

To change the LLM model, edit the `Agent(model=...)` parameter in `agent.py`.

See `backend/app/agent.py` for the full implementation.

## Troubleshooting

### Neo4j Connection Errors

**"Neo4j is unavailable" on all endpoints**
- Verify your `.env` file has correct `NEO4J_URI`, `NEO4J_USERNAME`, and `NEO4J_PASSWORD`
- Run `make test-connection` to validate credentials
- Run `make docker-up` first, then wait a few seconds for Neo4j to start

**Extra variables in `.env`**
- The backend accepts extra environment variables, so standard Neo4j Aura `.env` exports (with `NEO4J_DATABASE`, `AURA_INSTANCEID`, etc.) work without editing

### Backend Issues

**Port already in use**
- Change `BACKEND_PORT` in `.env` (default: 8000)
- Kill existing process: `lsof -ti:8000 | xargs kill`

**API key not set**
- Set `ANTHROPIC_API_KEY` or `OPENAI_API_KEY` in `.env` depending on your agent framework

### Frontend Issues

**Build errors after `npm install`**
- Delete `node_modules` and `package-lock.json`, then run `npm install` again
- Ensure Node.js 18+ is installed
